# Fine Wines Business Intelligence V1

This is a complete single-file GitHub Pages app.

Upload only `index.html` to the root of the repository. It contains all CSS and JavaScript inline, so there are no missing file-path issues.

Use with:
- Group sales overall 2024.xlsx
- Group sales overall 2025.xlsx

Columns used:
A SKU, B Description, C Pack Size, D Selling Price, E Sales Qty/Volume, G Cases, I Sales Value, L Profit, M GP%, Z Product Group, AA Product Type, AB Country, AE Department.
