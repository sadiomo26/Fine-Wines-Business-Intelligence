# Fine Wines Business Intelligence

Version 1 group-level sales dashboard.

## Files

- `index.html` - main page
- `css/styles.css` - styling
- `js/excel.js` - Excel parsing and comparison logic
- `js/dashboard.js` - dashboard rendering
- `js/app.js` - application controller

## Excel columns used

- A SKU
- B Description
- C Pack Size
- D Selling Price
- E Sales Qty / Volume
- G Cases
- I Sales Value
- L Gross Profit
- M GP %
- Z Product Group
- AA Product Type
- AB Country
- AE Department

## How to use

Open the GitHub Pages site, upload the overall 2024 and 2025 group sales files, then click **Build Dashboard**.
